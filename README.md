# 知图 (Atlas) 官网

知图产品官网，基于 **Astro + Tailwind CSS** 构建，苹果官网风格。

在线访问：<https://ratman463.github.io>

## 本地开发

```bash
npm install
npm run dev        # http://localhost:4321
```

## 构建

```bash
npm run build      # 输出到 dist/
npm run preview    # 本地预览构建产物
```

## 部署

GitHub Pages 已绑定该仓库（`ratman463.github.io`），push 到 `main` 后自动发布。

## 页面结构

| 区块 | 说明 |
|------|------|
| Hero | 大标题 + 副标题 + 三大功能示意 |
| About | 项目简介与设计理念 |
| Features | 三大核心功能 + 六项细节特性 |
| TechStack | 技术架构表 |
| Footer | 版权 / 协议 / 链接 |
